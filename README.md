# Cerro Dragón
Repositorio para la plataforma en línea de gestión y reserva de actividades en Cerro Dragón Tours.

> Nota: Hay que correr primero el API y luego el front, porque los dos intentan usar el puerto 3000 pero el 3000 lo tiene que usar el back porque el front lo llama quemado a ese puerto oops

```bash
cd API
npm run dev

cd CerroDragon
npm run dev
```
